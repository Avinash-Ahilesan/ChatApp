# ChatApp
A first-time approach at creating a secure chat application hosted on the web with end to end encryption.
## Features
### Authentication Features
- [x] Login, Logout, and Register
- [x] Session Expiry (Idle timeout)
- [x] Session Renewal Timeout
- [ ] Email verification
- [ ] Remember Me Function
- [ ] Rate Limiting + Account Lockout

### Chat Application Features
- [ ] Add/Remove A Friend
- [ ] Message a friend
- [ ] Call a friend

## Technologies Used
This project uses the MERN stack - MongoDB for long term data (such as login database), express for routing, react as the front-end framework, and Node.js for the server environment.

In addition to this, Mocha is used for the testing framework with chai as the assertion library.
